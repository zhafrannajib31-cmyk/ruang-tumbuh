⌘01 / TEKNOLOGI
Teknologi

Dasar Teknologi Informasi

Kenali perangkat keras, perangkat lunak, dan peran teknologi dalam kehidupan sehari-hari.

Teknologi informasi membantu proses pengumpulan, pengolahan, penyimpanan, dan penyebaran informasi. Contohnya adalah komputer, aplikasi, dan jaringan internet.
</>02 / CODING
Pemrograman

Pengenalan Pemrograman Web

Pelajari fungsi HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk interaksi.

HTML menyusun konten halaman. CSS mengatur warna, ukuran, dan tata letak. JavaScript membuat halaman lebih interaktif, misalnya melalui tombol dan pencarian.
◎03 / DIGITAL
Literasi Digital

Literasi Digital yang Aman

Pahami cara memeriksa informasi, menjaga data pribadi, dan berperilaku bijak di internet.

Biasakan memeriksa sumber informasi, menggunakan kata sandi yang kuat, mengaktifkan autentikasi dua faktor, dan tidak membagikan data sensitif sembarangan.

Materi tidak ditemukan. Coba kata kunci lain.
