EDUSPACE - WEBSITE UTS PEMROGRAMAN BERBASIS WEB

Cara menjalankan:
1. Ekstrak folder eduspace.
2. Buka folder tersebut di VS Code.
3. Buka index.html di browser (atau gunakan ekstensi Live Server jika tersedia).
4. Ganti [Nama Mahasiswa] dan [Nomor Induk Mahasiswa] pada index.html dengan identitas Anda.
5. Periksa semua bagian dan fitur sebelum mengunggah ke GitHub Pages atau Netlify.

Teknologi:
- HTML
- CSS
- JavaScript murni (tanpa framework)

Fitur:
- Navigasi responsif
- Mode terang/gelap (preferensi disimpan di localStorage)
- Pencarian materi
- Filter kategori materi
- Tombol baca selengkapnya
- Tautan referensi eksternal
- Tabel jadwal belajar

Catatan:
Google Fonts memerlukan koneksi internet untuk memuat font pilihan. Website tetap dapat digunakan jika font tersebut tidak tersedia.
